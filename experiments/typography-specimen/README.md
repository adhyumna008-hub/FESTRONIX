# Temporary typography specimen

Run from `D:\FESTRONIX`: `node experiments/typography-specimen/server.cjs`.

Open http://127.0.0.1:4177/. The local server serves only this specimen on loopback.

Choose any of nine combinations, or compare all. Light/dark controls apply equally to every pairing. Each embedded mobile preview is a real 390 px document and scrolls independently. For a standalone mobile view use `?sample=pulse-space` (or any ID shown in index.html); add `&surface=dark` for the dark surface.

Google Fonts are requested by the browser; internet access is needed. No font files are vendored. The page reports incomplete font loading so fallback text is not mistaken for the chosen family. Nine combinations share eight unique display families and Manrope. The comparison intentionally loads all candidates and is not a production performance pattern.

All sample event facts and participant details are fictional. Controls/forms are typography samples, not registrations. All fonts remain provisional. No production integration.
