# Public web design

Read `docs/AI_HANDOFF.md` and the applicable sections of `docs/THEME_REFERENCES.md`; use approved design documents when available. Distinguish reference evidence from provisional choices.

- Establish a clear reading order: festival identity, essential details, primary action, then supporting content.
- Use deliberate type scale, readable body text, controlled line lengths, and a consistent spacing rhythm.
- Compose for narrow screens as well as wide ones; preserve meaningful grouping and hierarchy when columns collapse.
- Make navigation easy to scan, with a clear active state and usable mobile treatment.
- Give event cards consistent information order and clear actions; accommodate long titles and variable metadata.
- Alternate section density and emphasis to create rhythm without inventing unrelated component styles.
- Keep each theme's typography, shapes, textures, and color choices coherent across the page. Preserve the shared content hierarchy.
- Translate reference principles into original FESTRONIX compositions and explain consequential visual choices.

Avoid generic AI landing-page formulas, arbitrary gradients, excessive glassmorphism, excessive glowing blobs, meaningless animations, random rounded cards everywhere, emoji icons, and exact copies of reference layouts.

Focus this skill on composition and visual language. Use motion guidance for animation behavior, performance/accessibility guidance for usability constraints, and browser visual QA for rendered verification when those tasks apply.
