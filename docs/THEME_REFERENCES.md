- **Spacing / navigation / hero:** Single focal identity with almost no surrounding interface; navigation absent in these frames. This may be an intro, not a complete hero.
- **Cards / borders and shapes:** No cards; illustrated panels and diagonal crops rather than UI containers.
- **Background / texture / lighting:** Dense ink artwork, grain, darkened center; flat graphic contrast rather than physical lighting.

- **Mobile:** Unknown; preserve readable identity and intentional crops if adapted.

- **Avoid:** Copying characters, logo, exact collage, illegible noise, mandatory long intro, flashing backgrounds.
